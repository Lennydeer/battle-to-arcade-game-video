# Лог изменений

## 2026-11-03 — Battle to Arcade Game Video

- Навык переименован из `battle-to-fighting-video` в `battle-to-arcade-game-video`: каталог, поле name, отображаемое название и пример вызова.
- Подготовлены README с установкой и использованием, самостоятельная экспликация и пакет для GitHub.
- Уточнена граница продукта: навык создаёт видео в стиле аркадного файтинга, не интерактивную игру и не готовый универсальный движок.
- Переименование не меняет утверждённый визуальный стиль и не изменяет ранее выпущенные ролики.

## 2026-11-03 — Обновление правил по производственным правкам

- Размеры и объём сверяются по голове, плечам, торсу и конечностям во всех позах, включая ходьбу, захват и финал.
- Анатомические стороны травм фиксируются относительно тела; повреждения сохраняются до лечения, одежда после лечения не восстанавливается автоматически.
- По умолчанию исключено зеркалирование; положение помощников и смена сторон требуют читаемого движения.
- Территория показывается внутри текущего бокового кадра с прежним масштабом; направление эффекта и рассечения соответствует действию.
- Исправлено универсальное требование лежащей позы: применяется фактический исход и утверждённый финал, включая явно выбранную сидячую позу.
- Отдельные встречи могут быть объединены в ролик по прямому запросу при сохранении причинного перехода.
- Для музыки фиксируются начало исходного участка и вход в видео; SFX привязываются к кадрам. Проверка после кодирования отделена от прослушивания.
- Добавлены hooks `scale_locked`, `anatomy_locked`, `audio_ready`; обновлены `defeat_settled` и `before_export`.
- Расширен шаблон сценария; решения конкретных боёв JJK вынесены в отдельный справочник.
- Сохранены Remotion для финального рендера, отсчёт 3–2–1, английский HUD, названия техник, трёхсекундные уведомления и выразительные smears.
